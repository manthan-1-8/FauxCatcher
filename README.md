# FauxCatcher
🕵️‍♂️ FauxCatcher

AI-powered Image Forensics and Tampering Detection System

FauxCatcher is an intelligent image verification tool designed to detect manipulated, AI-generated, or fake images using a combination of Error Level Analysis (ELA), metadata inspection, OCR-based fact-checking, and AI-driven feature extraction.
It integrates visual forensics, text validation, and reverse image search to provide a transparent, evidence-based trust score for digital images.

🚀 Features

🔍 Tampering Detection — Detects manipulated regions using Error Level Analysis (ELA).

🤖 AI-generated Image Identification — Checks if an image is synthetic or generated by AI.

🧠 Visual Similarity Search — Uses FAISS to find visually similar images from a dataset.

📝 Text Extraction & Fact Checking — Extracts text using EasyOCR and validates it via online search.

🧾 Metadata Analysis — Scans image metadata (EXIF) for inconsistencies.

🌐 Reverse Image Lookup — Performs internet-based reverse image search for verification.

⚙️ FastAPI + GCP Integration — Backend API built with FastAPI and deployed on Google Cloud Platform.

💻 Frontend: Simple web interface built with HTML, CSS, and JavaScript.
